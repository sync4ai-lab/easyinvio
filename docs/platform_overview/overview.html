EasyInvio.com: technology, architecture and capabilities

Repository review dated 18 October 2026. This describes implemented code, not a certification of deployed services, production readiness or provider acceptance. No secrets, customer records or live database inspection were used.

Architecture: an asynchronous Python/FastAPI modular monolith, a browser single-page application, Supabase PostgreSQL/Auth, external service adapters, durable SQL jobs and bounded optional OpenAI assistance. Pricing, financial locks and consequential-action authorization remain deterministic.

3. High-level features by persona

Platform Super Admin

  • Network revenue, stored markup, tenant and billing dashboards with date/environment filters.
  • Client onboarding, company and billing-plan administration; carrier connection management, verification and diagnostics.
  • Priority margin rules, lane/cargo selectors and platform-owned carrier access controls.
  • Search and open a client workspace with owner-level assistance; return to admin; attributable append-only request audit.
  • Support investigations, quote/freight cases, notification controls, credential replacement and agent usage metrics.

Client OWNER / ADMIN

  • Company settings, team membership and invitations, subject to each endpoint's role rules.
  • Warehouse addresses by role/default, saved contacts, SKU catalog and reviewed HS classifications.
  • Store connector configuration, order import/sync, dispatch workspace and bulk CSV processing.
  • Quotes, customs review, booking, labels, tracking, wallet/card payment flows and operational reporting.
  • Client support, invoice audit/dispute workflows and protection/claim workflows when eligible.

Warehouse DISPATCHER

  • Prepare imported or manual orders; select saved addresses/SKUs and capture measured multi-package contents.
  • Compare up to ten consolidated offers; review customs and confirm an explicitly selected booking.
  • Bulk dispatch, label/document bundles, shipment references, tracking and delivery exceptions.
  • Maintain catalogs where authorized; request parcel assistance or manual freight quotations.

Finance ACCOUNTANT

  • Wallet balance/activity and authorized Stripe top-up checkout; financial views subject to endpoint permissions.
  • Upload carrier invoices, compare exact saved cost snapshots and prepare/review dispute drafts.
  • Read catalogs and use permitted help/quote tools; no implied dispatcher booking or catalog-write authority.

Registered WhatsApp / web-chat user

  • Shared conversational gateway for QUOTE, BOOK_RESERVATION, TRACK_PACKAGE, TOPUP_WALLET, FILE_CLAIM and HELP.
  • Explicit commands work without an LLM; optional structured intent parsing handles ambiguous wording.
  • Actions inherit verified membership and role permissions. Quotes require complete saved route data; claims require confirmed cover.
  • Stable message receipts and ordered choices fence duplicate delivery and uncertain action replay.

Prospective customer / public visitor

  • Public Help Centre guides and clearly separated sample/preview workflows.
  • Opt-in WhatsApp company/profile/email registration with independent email and phone codes.
  • Verified provisioning creates OWNER membership, profile and a zero-balance GBP wallet; password setup uses Supabase Auth.

These are capability groupings, not a replacement for endpoint-specific permissions. A support operator is a platform-admin responsibility in the current implementation, not a separately guaranteed SUPPORT role. Assistance grants selected workspace-owner functionality and does not impersonate a particular employee's narrower role.

4. AI and documentation flow

LogisticsSupervisor coordinates ingestion, customs preparation, deterministic invoice/support delegates, optional MarginOptimizerAgent advice and HelpRetriever. The rate badge evaluates up to ten finalized offers within 1.5 seconds and cannot reprice, reorder or buy them. Invoice comparisons and tracking-ticket staging do not require an LLM. Explicit chat commands and WhatsApp registration also avoid model calls.

The Help Centre corpus is defined by backend/help_center.py GUIDES: built-in guide bodies plus the five root files docs_order_processing.md, docs_routing_rules.md, docs_tracking_branding.md, docs_returns_lifecycle.md and docs_carrier_pickups.md. backend/agents/rag_support.py splits sections, versions chunks and optionally ranks embeddings; its vector cache is output/agents. Answers cite /help/ guide sections. Keyword retrieval and related-guide fallbacks remain available when AI is off. This is documentation retrieval, not a search across customer records.

5. Implementation and activation boundaries

  • Carrier adapters and financial flows exist; live results require valid accounts, contracts, permissions, route eligibility, funding and environment alignment. Rate availability does not prove booking availability.
  • Road/sea freight: measured freight arithmetic and manual support intake exist. Native parcel adapters do not supply universal industrial freight quotes or sea bookings. Automatic courier pickup scheduling is not established.
  • Storefront intake and tracking are connector-specific. Shopify reverse-delivery tracking requires a verified native return reference; this is not universal automatic returns, refunds, restocking or exchange support.
  • Customs: official tariff search and reviewed data preparation exist. Human declaration review and destination-specific requirements remain necessary; no universal customs filing certification is claimed.
  • Protection and claims: estimation, policy/claim integration code and support intake exist, but sale/filing depends on configured provider coverage and permissions. A premium estimate alone is not purchased insurance or an approved claim.
  • WhatsApp signup requires migration 039, signed public HTTPS Twilio ingress, enabled signup, Supabase email OTP and production custom SMTP/password recovery configuration. New wallets start at zero.
  • Neither this inventory nor the historical repeated calculator matrix grants full UAT sign-off. Production credentials, deployed migrations and external acceptance need separate verification.
